# Stack Implementation Using Python

A menu-driven Python program that demonstrates the implementation of a Stack data structure.

## Features

- Push an element into the stack
- Pop an element from the stack
- Display the stack
- Stack Overflow handling
- Stack Underflow handling
- User-defined stack capacity

## Technologies Used

- Python

## How to Run

1. Run the `stack.py` file.
2. Enter the stack capacity.
3. Choose an option from the menu:
   - 1. Push
   - 2. Pop
   - 3. Display
   - 4. Exit
